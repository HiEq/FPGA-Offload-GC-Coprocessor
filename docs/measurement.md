## 计数正确性（`test_main` Test 1）

同一张图、同一个 `avg_refs=3`，FPGA 标记与同一套 BFS 的 C 实现（`fpga_gc_sw_mark`）逐行比较
`marked`；`test_main` Test 1 只输出计数，不输出耗时。七行 10–4000 全部 `OK`，出处
`tools/logs/board_test_main.log`。`marked < Objects` 是随机图中从根 0 不可达的对象。

### 适用条件

| 图所在位置 | CPU 每次依赖读 | 硬件（AXI HP，非一致） |
|---|---|---|
| DDR（非缓存） | 一次 DDR 往返，无重叠 | 同样往返，8 笔未完成读 + 对象头预取 |
| CPU cache | L1/L2 命中，几纳秒 | 仍走 AXI HP 到 DDR |

硬件仅在指针追逐受 DDR 延迟限制时占优（2.1–3.2×）；图驻留 cache 时为 0.5–1.0×。

## 测量条件

- `FPGA us` = `CYCLES` / 100 MHz：只含引擎时间，不含构图、写对象头、清队列轮询、驱动 `usleep`。
- `C us`：同一张图、同一 BFS 的 C 实现，与引擎同阶段；图在 DDR、驱动不做 cache 维护，即**未缓存**访问。
- C（缓存）：同一 BFS 运行在堆副本上的上限参照（`fpga_vs_c_vs_python.py` 的 C-c 列）。
- `py_bfs.py`：Python 字节码 BFS（逐条读 `/dev/mem`），只作量级参照（17–221×）。

## 端到端成本

`fpga_vs_python.py 4096 8 2`（`tools/logs/board_v412_800mhz.log`）：

| 阶段 | 时间 |
| --- | --- |
| 构图 + 写 DDR（Python 3.12，含 1 MiB memset 与引用数组）| 102.2 ms / 图平均 |
| 同一张图的 Python BFS（oracle）| 43.8 ms / 图平均 |
| 硬件标记（引擎）| 0.214 ms / 图平均 |

单次卸载的端到端成本由构图主导（约 478× 标记时间）。构图走 Python；
`fpga_gc_build_graph()` 未单独计时，同样不计入 `FPGA us`。

## 证据边界

`tools/logs/` 中每条日志头部写明命令、位流、BOOT 哈希、提交与日期；引用数字前先核对哈希。
不同位流下的 C 基线不可直接比较。
